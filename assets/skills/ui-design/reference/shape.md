# Shape

Planning-only command: output a **confirmed brief**, zero implementation.

## Discovery (no visuals yet)

Hold code and world selection. Prefer the structured question tool; otherwise ask once and pause.

| Cadence rule | Detail |
|--------------|--------|
| Batch size | 2–3 linked questions, then stop for answers |
| Rounds | Default 1; round 2 only if answers expose a gap |
| Style | Infer likely answers; invite correction—no surveys |

**Round A — outcome:** Pick the highest-leverage unknowns among purpose, audience mindset, success criteria, and claims only this product can make.

**Round B — material:** Only if still open: asset ranges, critical states (empty/error/permission), fidelity target, forbidden changes, hard constraints (platform, a11y, locale, perf).

Visual lanes and CSS numbers belong in the new-work playbook, not here.

## Direction handoff

Greenfield, rebrand, or new surface identity: walk the new-work playbook through authority + concept selection, then **return** before writing contracts or code. Inside a locked world, run concept exploration only when layout or interaction is still undecided.

## Brief skeleton

| Block | Content |
|-------|---------|
| Audience & mode | Who, context, visitor mode |
| Proof | Task, success signals, evidence |
| Direction | Thesis, focal moment, build implications |
| Fence | Scope, anti-goals, untouched areas |
| Data | Content ranges, state matrix |
| Layout intent | Hierarchy & topology (not properties) |
| Open items | Explicit decisions builders must not guess |

Short briefs get bullets; messy multi-screen asks get the full table. No transcript replay.

## Exit

User confirms (or one revision pass) → **stop**. Shape never ships code or persists direction contracts.

Unattended: list assumptions inline in the brief, deliver, stop.
