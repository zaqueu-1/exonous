# Init

Captures **product truth** in `PRODUCT.md`. Visual worlds stay out—see new-work (create) or document (record incumbent). Web apps may gain live config under engine state directory.

## 1 · State

Use context-resolved product path. Update, don't fork. Child apps: confirm inherited vs local scope.

| Case | Move |
|------|------|
| Absent file | Explore + interview + write |
| Exists | Patch stale fields only |
| Legacy | Add facts; default platform web |
| Design file only | Add product file; don't touch design file |
| Rebrand request | Keep product facts; visuals later |

Finish interrupted init before other work. Shape interviews resume first.

## 2 · Recon

Scan docs, packages, routes, brand assets, a11y hints, dev entry. Hypothesize platform: web | ios | android | adaptive (true dual-language products). Mobile site = web.

## 3 · Interview

AskUserQuestion for gaps only. ≤3 rounds. Prove answer channel exists before unattended inference; label inferred facts in output + first reply.

Topics: user/job, differentiated value, durable constraints/assets. Greenfield stack: user chooses framework or delegates—record under Stack section. No visual preference interviews.

## 4 · Write product file

Template sections: Platform, Stack (if needed), Users, Purpose, Positioning, Context, Capabilities, Brand, Evidence, Principles, Accessibility. Omit empty sections.

First line after the title: the engine's schema stamp, verbatim — `<!-- impeccable:product-schema 1 -->` (the engine parses it; keep it when updating an older file, change the number only when this template changes). Sections reported as deprecated at boot are removed only with the user's agreement.

Platform ios/android/adaptive → load platform playbooks before design (context could not pre-load).

Gate: file exists at resolved path with substantive content—no stand-in notes.

## 5 · Defaults

**buildPath** (when image tools exist, unset): ask comp-first vs code-first once → engine config JSON. Silent session default if unanswered. Respect stored value/local override.

**Live:** first-time live setup when runnable web; CSP edits need consent.

## 6 · Handoff

Summarize open vs captured. Suggest shape, document, scoped command, or live based on state. Resume parent task without context rerun.
