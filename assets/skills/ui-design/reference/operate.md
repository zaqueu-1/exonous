# Operate depth (+ Read crossovers)

Task-first surfaces: apps, admin, settings, dense tables, authenticated tools. Pair with SKILL.md **Operate** mode and the craft floor. **Read** mode docs lean on measure, nav, and type rhythm here—density matters less than clarity.

## Trust test

Users fluent in the category should never pause at alien controls. Decorative chrome, mixed control families, or motion without state meaning breaks trust faster than flat layout.

## Type in product chrome

Single sans stack is normal. Step sizes ~1.125–1.2 rem—not marketing fluid clamps. Prose blocks ~65–75ch; data grids may widen.

## Color in product chrome

Bias **Restrained** palettes; occasional **Committed** fields (report accent, onboarding splash). Map full semantic states. Accent marks primary action + selection—not wallpaper. Secondary neutral for rails/panels.

## Layout & motion

Breakpoints reshape structure (nav collapse, table modes)—not display fluid type. Transitions ~150–250ms, state-only, no staged page entrances.

## Components

Ship complete state matrices; skeleton placeholders; teaching empty states; portals/`dialog`/popover for overlays escaping scroll clipping.

## Don't / Do

Avoid display type on controls, novelty scrollbars, modal-first flows, mismatched buttons, idle saturated chrome.

Do use familiar nav idioms, justified density, cross-screen consistency—delight only at earned moments.
