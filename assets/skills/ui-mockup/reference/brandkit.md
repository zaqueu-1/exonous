# Brand-kit boards (image)

Single (or few) **presentation-grid** images: logo exploration, color/type specimens, mockup applications, atmospheric panels—identity-deck quality, not random moodboards.

## Strategic core

Each board argues: what the brand stands for, core metaphor, how the mark encodes it, how the system scales across digital/print/image, why it feels ownable. Infer category, audience, promise, trust level, and what to avoid **before** rendering.

## Default deliverable

Unless specified otherwise:

- **One overview image**  
- Layout: **3×3** grid (alternatives: 2×3 deck, 2×2 compact, 1×3 strip, 4×2 wide)  
- Aspect: **4:3** or **16:10**  
- Strong gutters, aligned panels, sparse type, connected rhythm  

Quality bar: dark or light presentation canvas, restrained density, cinematic atmosphere where appropriate, halftone/grain/print texture optional, construction geometry panel optional, small page-number-style details sparingly.

## Logo standard

Simple, memorable, scalable mark tied to meaning—works as icon, wordmark, badge, UI glyph. Avoid clipart, random animals, unjustified lightning bolts, overcomplex crests, inconsistent variants across panels.

### Concept methods (use one or combine two max)

1. **Monogram + metaphor** — initial merged with geometry (cuts, folds, negative space).  
2. **Product action** — abstract symbol of build, protect, convert, speak, automate, etc.  
3. **Metaphor fusion** — two ideas reduced to one readable mark.  
4. **Negative space** — hidden arrow, protected core, path in counterforms.  
5. **Construction geometry** — circles, grids, modular blocks; one panel may show construction lines.

## Panel rhythm (3×3 default)

1. Logo cover — mark + wordmark, huge whitespace  
2. Construction — grid, breakdown, rationale  
3. Digital application — browser bar, app header, terminal fragment, or icon  
4. Brand essence — one short tagline, large type  
5. Color system — swatches, chips, disciplined accents  
6. Typography — specimen or pairing  
7. Physical — card, seal, label, packaging fragment  
8. Image direction — cinematic landscape, product crop, textured atmosphere  
9. System detail — chips, inputs, icon row, pattern snippet  

Alternate **2×3 deck:** logo → product surface → functional/command panel → atmosphere image → construction/badge → tagline promise.

Vary panel loudness: quiet / functional / emotional / technical—not nine equal shouts.

## Text & taglines

Minimal copy: brand name, one tagline, URL or install command, 2–5 section labels, short UI chips. No paragraphs, lorem, dense menus. Taglines specific and short—not buzzword soup.

## Mockups & imagery

Mockups are **identity applications** (browser chrome, terminal, icon, card, seal)—not feature-complete fake dashboards. Images: cinematic landscapes, graded product crops, controlled halftone—match palette and metaphor; skip stock office clichés and random robots.

## Color discipline

One dominant system: base, primary accent, secondary accent, neutrals. Accents repeat across panels. No rainbow unless requested; no default purple-blue glow unless brand fits.

## Reference images from user

Extract: grid rhythm, density, type scale, logo placement, text amount, treatment, accent logic. Do **not** copy exact marks, names, slogans, or unique assets.

## Anti-generic

Floating icon salads, startup mesh gradients, inconsistent logos panel-to-panel, neon soup, PowerPoint-style clutter, meaningless blobs, busy fake UIs.

## Internal prompt skeleton

Brand name + category + audience + personality + core metaphor + logo idea → grid layout + panel list + visual mode + palette → style: sparse, cinematic, intentional, guidelines-deck polish, ownable mark repeated consistently.

## Output standard

Should read as senior identity presentation: strategic, minimal, coherent, art-directed, usable as north star for **`ui-design`** / product UI—not a template stock board.
